# AUREL — Android-диктофон

Нативный Android-интерфейс по утверждённому прототипу: обсидиановый фон, латунный циферблат почти на всю ширину экрана, таймер внутри прибора и плавная волна под ним. Управление находится в одной нижней строке. Демонстрационные записи веб-прототипа в Android-приложение не добавляются.

## Установить готовый APK

Файл для скачивания: [releases/AUREL-1.1.apk](releases/AUREL-1.1.apk). На странице файла в GitHub нажмите **Download raw file** (значок скачивания). Контрольная сумма находится рядом в `releases/AUREL-1.1.apk.sha256`.

Это тестовая сборка версии 1.1 (versionCode 2), подписанная отладочным ключом. Устанавливайте поверх предыдущей версии при совпадении подписи, не удаляя приложение с локальными записями.

## Использование

- Центральная латунная кнопка запускает запись, ставит её на паузу и продолжает. Таймер не учитывает время на паузе.
- Флажок добавляет маркер с временем внутри текущей записи.
- Квадрат открывает название и сохранение. Отмена возвращает прежнее состояние записи.
- Кнопка архива открывает настоящие записи; доступны поиск, избранное, встроенный проигрыватель и перемотка.
- Долгое нажатие на файл открывает удаление или список маркеров. Выбор маркера начинает воспроизведение с этого момента.
- Запись продолжает работать в фоновом сервисе. В уведомлении доступны пауза, продолжение и завершение.

Стрелка показывает уровень микрофона, а не направление на источник звука. Волна визуализирует огибающую уровня, полученную через MediaRecorder, с плавной интерполяцией между измерениями. На паузе анимация замирает; состояние прибора сохраняется при пересоздании экрана. Системное отключение анимации учитывается.

## Звук и хранение

Используется существующий движок MediaRecorder: AAC в контейнере M4A, 44,1 кГц, подбор поддерживаемого битрейта и каналов. Формат WAV из демонстрационного прототипа не означает изменение аудиодвижка.

На Android 10+ готовые файлы публикуются в `Music/MeetingRecorder` через MediaStore. До успешной публикации сохраняется локальная копия. Если медиатека недоступна, запись остаётся в приложении и появляется в архиве. На Android 7–9 записи находятся во внутреннем хранилище приложения. Избранное и маркеры хранятся локально.

## Сборка

JDK 17+, Android SDK 34, Build Tools 34.0.0. Минимальная версия Android — 7.0 / API 24; target SDK — 34. UI: XML, AppCompat, Material 3, RecyclerView и собственная отрисовка Canvas. Kotlin 1.9.24, Gradle 8.7, AGP 8.5.2.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Для этого облачного окружения перед Gradle выполните `source /workspace/.android-env/activate.sh`.

## Проверки

- JVM-тесты таймера: пауза, продолжение, повторные команды и сброс между записями.
- Robolectric с нативной графикой Android 14: переходы между студией и архивом, доступность нижнего управления, отрисовка на экранах 320×568, 390×780 и 480×900, неподвижность сигнала на паузе.
- Проверка хранения: при недоступной MediaStore аудиофайл остаётся в локальном архиве, маркеры сохраняются и удаляются вместе с записью.
- PNG предпросмотра: `app/build/reports/aurel/`; отчёт тестов: `app/build/reports/tests/testDebugUnitTest/`.

Для окончательной проверки звука нужны физический телефон и разрешение микрофона: проверить запись → пауза → продолжение → сохранение → воспроизведение, затем запись с выключенным экраном и действия уведомления. Локальные тесты не проверяют реальный микрофон или ограничения фоновой работы производителя телефона.
